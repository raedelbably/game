# كاشف الكذب (مقلب ترفيهي) — دليل البناء والنشر

مشروع Expo / React Native واحد يُبنى لأندرويد وآيفون.

## ما الذي يعمل
- بصمة الإصبع + موجة نبض القلب + رقم BPM متصاعد + حلقات نابضة.
- نبضات قلب صوتية تتسارع، واهتزاز متصاعد.
- نتيجة بعد 5 ثوانٍ: «حقيقة» أخضر أو «كذب» أحمر.
- التحكم السري أثناء الفحص:
  - زر رفع الصوت = حقيقة، زر خفض الصوت = كذب.
  - أو الزاوية السفلية اليسرى (حقيقة) / السفلية اليمنى (كذب) غير المرئيتين.
- لوحة سرية: اضغط الشعار 3 مرات سريعة. منها: التحكم السري/العشوائي، وتفعيل الفلاش أثناء الفحص (يطلب إذن الكاميرا).

## متطلبات الحسابات
- Google Play Console: رسوم 25 دولاراً مرة واحدة.
- Apple Developer Program: 99 دولاراً سنوياً (ضروري للآيفون).
- حساب مجاني على expo.dev.

## الخطوات
```bash
npm install
npm install -g eas-cli
eas login
eas init                      # يربط المشروع بحسابك
```
غيّر `com.raed.liedetectorprank` في app.json (ios.bundleIdentifier و android.package) إلى معرّف تريده قبل أول بناء، ولا يمكن تغييره بعد النشر.

**اختبار على جوالك (مهم):** المشروع يستخدم مكتبة أزرار الصوت الأصلية فلا يعمل في Expo Go.
```bash
eas build --profile preview --platform android     # ملف APK تثبّته مباشرة
eas build --profile development --platform ios     # للآيفون، يحتاج حساب Apple
```

**النشر:**
```bash
eas build --platform android --profile production  # ملف AAB لمتجر بلاي
eas build --platform ios --profile production
eas submit --platform android
eas submit --platform ios
```
في بلاي: أنشئ التطبيق في Play Console وارفع أول AAB يدوياً مرة واحدة، ثم يعمل `eas submit`. التطبيقات الشخصية الجديدة تحتاج اختباراً مغلقاً بـ 12 مختبراً لمدة 14 يوماً قبل الإنتاج.

## بيانات صفحة المتجر
- الاسم: كاشف الكذب - مقلب
- الوصف القصير: مقلب ممتع مع أصدقائك: ضع إصبعك وانتظر النتيجة!
- الوصف: تطبيق ترفيهي يحاكي جهاز كشف الكذب بالبصمة ونبض القلب مع اهتزازات وأصوات واقعية. للتسلية فقط، ولا يكشف الكذب فعلياً.
- التصنيف: ترفيه (Entertainment). العمر: 3+/4+.
- سياسة الخصوصية: التطبيق لا يجمع أي بيانات ولا يتصل بالإنترنت. اكتب ذلك في صفحة بسيطة وضع رابطها (مطلوب في المتجرين).
- إذن الكاميرا: للفلاش فقط، ولا تُلتقط أي صور.

## ملاحظات لقبول المتجرين
- اذكر في الوصف والشاشة أنه «للتسلية فقط» (موجود أسفل الشاشة). لا تدّعِ أنه يقيس شيئاً طبياً.
- أبل أصعب في قبول تطبيقات المقالب؛ أبقِ عبارة الترفيه واضحة في لقطات الشاشة.
- إخفاء واجهة الصوت وتغيير مستوى الصوت إلى 50% عند بدء الفحص مقصودان ليعمل زرا الرفع والخفض، ويُعاد إظهار الواجهة عند الانتهاء.
